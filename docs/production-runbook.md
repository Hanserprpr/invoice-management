# D5 生产上线与验收手册

本手册记录可复现的上线步骤和验收证据。任何真实密钥、Cookie、原始发票或个人信息都不得提交到仓库。

## 1. 生产配置

使用 `prod` Profile 启动。应用会在启动后拒绝测试库、本机数据库、占位密钥、未启用 R2 或未启用 Redis 限流。生产必须从密钥管理服务注入：

- MySQL：`MYSQL_URL`、`MYSQL_USERNAME`、`MYSQL_PASSWORD`；
- Redis：`SPRING_DATA_REDIS_URL`，用于跨实例 Session 和限流；
- OIDC：`SDU_OIDC_CLIENT_ID`、`SDU_OIDC_CLIENT_SECRET`；
- R2：`R2_ENABLED=true`、账号、Access Key、Secret 和私有桶名；
- ClamAV、OCR、通知投递按试点决定启用，未启用时必须保留人工闭环；
- `RATE_LIMIT_ENABLED=true`，按容量测试调整窗口和额度。

外部入口只允许 HTTPS。反向代理仅从受控代理写入转发头；R2 桶禁止公共访问，CORS 只允许正式前端域名和必要方法。Actuator 只公开不含详情的存活/就绪探针；Prometheus 端点须由内网或网关认证保护。

## 2. 密钥轮换

1. 在提供方创建第二把有效密钥，不覆盖旧密钥；
2. 更新密钥管理服务并滚动发布，确认 readiness、登录、上传和异步任务；
3. 检查错误率、任务积压和对象访问 30 分钟；
4. 撤销旧密钥，再次执行冒烟检查；
5. 记录轮换人、时间、密钥版本和验证结果，禁止记录密钥正文。

数据库密码需先创建新用户/授权后滚动切换，再删除旧用户。OIDC、R2、OCR 和通知密钥每 90 天轮换，疑似泄露时立即轮换。

## 3. 备份、恢复和迁移回退

使用 `scripts/backup-mysql.sh` 生成事务一致的压缩备份及 SHA-256。恢复脚本只接受以 `_restore_test` 结尾的隔离数据库，防止覆盖生产库。每次发布前备份，并至少每季度执行一次恢复演练：

1. 建立空的 `invoice_management_restore_test`；
2. 执行恢复脚本，记录耗时和校验结果；
3. 用只读账号核对 42 张业务表、Flyway 历史、关键记录数和随机业务记录；
4. 在恢复库启动同版本应用并运行只读冒烟测试；
5. 销毁演练库并保留不含业务正文的验收记录。

Flyway 迁移只前进不自动执行 down。发布失败时先停止写流量；代码兼容则回滚应用，结构不兼容则从发布前备份恢复到新实例并切换连接，禁止修改已执行迁移文件。

本地基线证据：2026-08-13 在 MySQL 8.4 Docker 环境中从 `invoice_management_test` 生成压缩备份，SHA-256 校验通过，并成功恢复到临时 `invoice_management_restore_test`，校验到 42 张业务表和 1 张 Flyway 历史表；验证后已删除临时库。该结果仅证明脚本基线可用，不替代正式环境的定期恢复演练。

## 4. 多实例和监控

- HTTP Session 存入 Redis；实例不依赖粘性会话；
- 异步任务通过 MySQL `FOR UPDATE SKIP LOCKED` 竞争领取，超时任务可重调度；
- 同一业务目标使用唯一约束、乐观锁或活动任务查询实现幂等；
- readiness 同时检查数据库、Redis 和超时异步任务；
- 告警至少覆盖 5xx、401/403 异常增长、429、P95/P99 延迟、数据库连接池、Redis、异步失败/积压、R2/OCR/通知失败和磁盘容量；
- 日志以 `X-Request-Id` 关联，禁止记录 Authorization、Cookie、OIDC/R2 密钥和文件正文。

建议告警线：5 分钟 5xx 比例超过 1%；P95 超过 2 秒；最老 PENDING 任务超过 10 分钟；出现 20 分钟以上 RUNNING 任务；数据库或 Redis readiness 失败立即告警。

## 5. D5 验收证据表

以下项目必须填写执行时间、环境、执行人、结果和证据位置，不能仅勾选：

- [ ] 20—30 张真实脱敏发票的二维码/OCR 回放；先运行 `verify-replay-corpus.sh`，语料放在仓库外；
- [ ] PRD 第 18 章 15 步端到端场景；
- [ ] 第二社团对项目、发票、文件、导出产物的水平越权全部拒绝；
- [ ] 缺失/伪造租户头、管理员入口、批量上限和下载重新授权；
- [ ] 两个应用实例交替访问同一 Session；
- [ ] 两个 Worker 并发领取任务且没有重复产生业务结果；
- [ ] 备份、校验、隔离恢复和恢复后启动；
- [ ] R2/OCR/通知超时与重试降级；
- [ ] 换届后新负责人访问历史项目，旧负责人即时失权；
- [ ] 清除试点测试账号、临时对象、测试密钥及开发数据；
- [ ] 试点负责人确认字段、字典、纸票需求、导出格式和最终结果。

未完成任一项时，D5 状态必须保持“待正式环境验收”。
